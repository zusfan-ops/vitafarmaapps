🔄 ALUR KERJA

Dari Resep Sampai Pesanan Selesai

Pelanggan, apoteker, gudang, dan kurir bekerja dalam satu alur terintegrasi yang transparan.

  1. 1

    Pelanggan Pesan

    Pelanggan mencari produk atau mengunggah foto resep dokter melalui PWA atau aplikasi Flutter.

  2. 2

    Verifikasi Apoteker

    Apoteker Penanggung Jawab memeriksa legalitas resep, dosis, dan ketersediaan stok obat.

  3. 3

    Staf Gudang Menyiapkan

    Item dikeluarkan dari lokasi etalase/batch sesuai kartu stok; stok berkurang otomatis.

  4. 4

    Kurir Mengantar / Pelanggan Ambil

    Status pesanan diperbarui; pelanggan bisa melacak progress secara real-time.

🛠️ TEKNOLOGI

Dibangun dengan Stack Modern & Andal

Laravel

Backend

Laravel 13 + PHP 8.3+ dengan REST API first-party dan session-based auth.

MySQL

Database

MySQL 8.4 sebagai satu sumber kebenaran data produk, stok, pesanan, dan resep.

Flutter

Mobile

Flutter 3.44 + Dart 3.12 + Riverpod untuk aplikasi pelanggan dan staf.

PWA

Web App

Manifest + service worker, cache-first statis, network-first data, splash screen.

REST

API

Endpoint terpisah untuk pelanggan dan staf, dilindungi CSRF & validasi ketat.

Sanctum

Auth

Laravel Sanctum untuk Bearer token di aplikasi Flutter; cookie session untuk PWA.
